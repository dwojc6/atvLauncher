# ATLauncher

## Version 1.6

- Added Haze CupertinoMaterials surfaces for the dock, status bar, folders, input tiles, and long-press menus.
- Disabled Haze noise for a cleaner TV presentation.
- Made TV input tiles without custom artwork solid.
- Reduced bitmap memory usage and added low-memory cache eviction.
- Refreshes installed apps from package-change broadcasts instead of every resume.
- Minimum Android version is now API 28.

## Version 1.2

- Added Apple TV style folders.
- Added real-time blurred folder backdrop instead of relying on pre-blurred wallpaper assets.
- Migrated launcher blur effects to Haze.
- Enabled Haze blur on older Android versions as well.
- Improved move/focus behavior.
- Fixed folder app move menus and nested move dialogs to register correctly on first press.
- Added Network option to the settings menu below System.
- Fixed wake/resume handling as well as launch on boot.
- Fixed settings menu focus being preserved when returning from submenus and external settings screens.
